02 · Capabilities

  
Everything the platform
can do today.

  
An inventory, not a wishlist: every feature carries its honest stage. Anything not in production is labeled “code ready” or with a launch year.

  

    
live
      
Truthful data

      
    
        
  • Every metric carries a quality flag: complete, partial or unavailable — the trust level is visible at a glance.
    • 
        
  • “—” instead of zeros: missing data never pretends to be a value; demo mode only with ?demo=1 and a “DEMO DATA” badge, disabled by flag in production.
    • 
        
  • One event layer: on-chain and off-chain, deduplication, cursors, backfill, gap detection and healing.
    • 
      

    

    
live
      
Economy under lock

      
    
        
  • 40 metrics in 8 families: mint/burn, sources and sinks, velocity, fairness, risk, game interweaving.
    • 
        
  • A 0–100 health index for each game and for the whole ecosystem — one number with a full breakdown.
    • 
        
  • Golden tests + a 0.8 mutation gate: a formula cannot break silently — CI fails first.
    • 
      

    

    
live
      
Control without keys

      
    
        
  • Changes only via proposal: 2 signatures + 2FA, an audit log for every action, an emergency pause.
    • 
        
  • The hub cannot sign transactions: enforced by the test:readonly suite, not by a promise.
    • 
        
  • Contracts as specification: cross_game_inventory, studio_treasury, session_keys — verifiable invariants and writes: false.
    • 
      

    

    
code ready
      
Traffic with proof

      
    
        
  • “Post → game” visits confirmed by click-id without PII, honouring DNT/GPC — attendance is proven, not guessed.
    • 
        
  • 21 counters + an integrity layer: bots and humans kept strictly apart; duplicates, gaps and rate limits visible, not hidden.
    • 
        
  • Funnels up to 6 steps, cross-game segments and campaigns: from the source to the first match.
    • 
      

    

    
live
      
The investor layer

      
    
        
  • Reports, snapshots and trends via API: a share holder sees the same numbers as the founder.
    • 
        
  • Maturity levels L0–L4 per game, ecosystem target coverage and audit finding totals.
    • 
        
  • The “Get to work” button: a ready Arena prompt straight from the dashboard — from report to action in one click.
    • 
      

    

    
live
      
Big-league operations

      
    
        
  • One non-root container: healthcheck, graceful shutdown, Prometheus metrics on /metrics.
    • 
        
  • Studio release pipeline: release:check across every repo, a no-side-effects plan, deploy only with an explicit flag.
    • 
        
  • Privacy by default: PII is pseudonymised with a salt, erasure on request, retention; secrets only via env — startup fails fast without them.
    •
