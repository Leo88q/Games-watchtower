```bash

# or npm
npm i -g @sentio/cli
```

## Quick Start
```bash
sentio scan --program ./programs/cross_game_inventory
sentio scan --program ./programs/session_keys --severity high
sentio audit --anchor --report json
sentio scan --ci --fail-on high
```
