# Watchtower OS — Мастер-промты для всех команд студии

## Что это
Watchtower OS v1.0 — мультитенантная ОС игровой студии, внедрена в этом репо `Games-watchtower`.
7 слоёв + 5 движков + 3 контракта + 8 API групп + SDKs + Frontend панель.

API OS: `GET /api/os/config` — вся конфигурация, `GET /api/os/health` — health всех слоёв.
Frontend: `npm run dev` -> http://localhost:5173 — панель с 8 карточками слоёв.

## Как взаимодействовать с OS — единый контракт

### Для всех команд
- Watchtower OS — read-only, `blockchain_writes_enabled 0`, не может делать blockchain writes
- Все writes через client-side signing: Phantom deep links, Mobile Wallet Adapter, Session Keys (временный keypair 0.01 SOL), gasless relay FirstStep/Altude/GameShift/MagicBlock
- События в inbox: `POST /api/ingest/solana` с canonical identity `cluster+slot+signature+instructionIndex+innerIndex` для дедупликации
- Обязательное поле для аналитики: `payload.solana_wallet` как `external_id` для GameSight Late ID Binding
- Cross-game PDA: `studio_profile` — Anchor `CgInv111...` — общие PDA для кросс-игрового инвентаря
- ENV: смотри `.env.example` — только имена переменных, без значений, секреты никогда в git

### Базовый flow игрока
1. Guest (FirstStep) — игрок заходит без кошелька, получает gasless гостевой кошелек, спонсорство газа
2. Embedded (Privy) — при первом входе через email/social автоматически создаётся Solana-кошелёк в secure enclave, `useCreateWallet`, `useSolanaWallets`, экспорт возможен
3. Native (Phantom Connect Kit) — OAuth-логин, мгновенное создание кошелька, для crypto-native
4. Linked — все кошельки линкуются в `studio_profile` PDA, cross-game inventory
5. Session Keys — `createSession(targetProgram, topUp 0.01 SOL, expiry 60min)` временная пара на клиенте, session token, `signAndSendTransaction` без раскрытия приватного ключа основного кошелька, риск ограничен 0.01 SOL, scope denied `withdraw_treasury`, `update_authority`, `mint_unlimited`
6. Assets — cNFT для массовых (1M ~ $110 off-chain Merkle Tree MCC Bubblegum v2 Tensor fallback ME deprecated) + Standard NFT для редких
7. L2 — Sonic HyperGrid dedicated grid thousands no contention high frequency, Sorada 5ms 30-40x reads, Rush ECS declarative, REPLA repla-cli L3 Anchor settle MagicBlock sequencer, MagicBlock ER sub-10ms gasless Magic Actions auto triggers
8. Analytics — Helika cross-game dashboard Web2 in-game on-chain + GameSight ad->on-chain attribution solana_wallet external_id Late ID Binding mint buy sell transfer burn Anonymous Events Wallet ID
9. Marketplace — Magic Eden 120 QPM free Bearer MCC+MT, Shyft escrow-less in-app за дни stats API, GameShift USD 170+ стран 100% chargeback газ берёт на себя

## Как запустить Watchtower OS

```bash
npm install
npm run dev:api # 0.0.0.0:8787 Watchtower OS API 7 layers
npm run dev # 0.0.0.0:5173 Vite proxy /api to 8787
```

Проверка:
```
curl http://localhost:8787/api/os/config | jq
curl http://localhost:8787/api/os/health | jq
curl http://localhost:8787/api/identity/health | jq
curl http://localhost:8787/api/session-keys/health | jq
curl http://localhost:8787/api/assets/strategy?gameId=ares1&itemType=common&rarity=common | jq
curl http://localhost:8787/api/l2/router?gameId=ares1&tps=high | jq
curl http://localhost:8787/api/marketplace/router?gameId=ares1&assetType=cnft | jq
curl http://localhost:8787/api/sdk/unity?gameId=ares1 | jq
```

Frontend: http://localhost:5173 — Watchtower OS панель
