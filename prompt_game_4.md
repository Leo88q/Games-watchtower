# Аудит игры для Games Watchtower

## Игра 4 — `[НАЗВАНИЕ ИГРЫ 4]`

Ты работаешь как технический аудитор и product/data analyst проекта **[НАЗВАНИЕ ИГРЫ 4]**. У тебя есть доступ к репозиторию, документации, конфигурации и доступным сервисам проекта.

Твоя задача — провести фактический аудит проекта для последующего подключения к централизованной панели управления **Games Watchtower**. Не додумывай информацию. Если данных нет, напиши `НЕ НАЙДЕНО`. Каждый вывод подтверждай ссылкой на файл, путь, таблицу, endpoint, dashboard или другой источник.

### Правила ответа

1. Сначала изучи структуру проекта и существующую документацию.
2. Не изменяй код и конфигурацию.
3. Не раскрывай секреты, API-ключи, токены, seed-фразы, приватные ключи и пароли. Показывай только имена переменных, типы и область применения.
4. Разделяй факты, предположения и рекомендации.
5. Для каждого числового показателя укажи формулу, источник, период агрегации и часовой пояс.
6. Если метрика не собирается, укажи, какие события нужны для её расчёта.
7. Ответ должен быть конкретным и техническим, без маркетинговых формулировок.
